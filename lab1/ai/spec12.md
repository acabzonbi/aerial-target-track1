Застосунок для відстеження повітряних цілей над Україною, та оповіщенням у разі небезпеки для обраного міста/регіону.

Користувач обирає місто і радіус, вказує які цілі хочу відстежувати(ударні/розвідувальні дрони, балістичні/крилаті ракети або інші). Коли зафіксована ціль наближається до міста і може становити для нього загрозу, система надсилає підписникам сповіщення обраним способом(PUSH, месенджери).

Усі ідентифікатори (PK і FK) мають тип `string`.


# Сутності:

**REGION** (область)
- region_id (PK): унікальний ідентифікатор області
- name: назва області

**CITY** (місто)
- city_id (PK): унікальний ідентифікатор міста
- name: назва міста, string
- latitude: широта центру міста, float
- longitude: довгота центру міста, float
- region_id (FK - REGION): область, у якій розташоване місто

**USER** (користувач)
- user_id (PK): унікальний ідентифікатор користувача

**SUBSCRIPTION** (підписка користувача на місто)
- subscription_id (PK): унікальний ідентифікатор підписки.
- user_id (FK - USER): користувач, який підписався.
- city_id (FK - CITY): місто, на яке оформлено підписку.
- alert_radius: відстань у кілометрах від міста, у межах якої користувач хоче отримувати сповіщення, int

**AIR_TARGET** (повітряна ціль)
- target_id (PK): унікальний ідентифікатор цілі
- target_type: тип цілі, string
- latitude: широта позиції цілі, float
- longitude: довгота позиції цілі, float

**DATA_SOURCE** (джерело даних)
- source_id (PK): унікальний ідентифікатор джерела.
- name: назва джерела, звідки надходять дані, string

**THREAT_CALC** (розрахунок загрози цілі для міста)
- calc_id (PK): унікальний ідентифікатор оцінки
- target_id (FK - AIR_TARGET): ціль, яку оцінено
- city_id (FK - CITY): місто, для якого оцінено загрозу
- calc_at: час коли останній раз робився розрахунок, float

**NOTIFICATION** (сповіщення користувачу)
- notification_id (PK): унікальний ідентифікатор сповіщення
- user_id (FK - USER): користувач, якому надіслано сповіщення
- calc_id (FK - THREAT_CALC): розрахунок загрози, через яку створено сповіщення

# Зв'язки
- REGION - CITY: область має від 1 до N міст, місто належить рівно 1 області
- USER - SUBSCRIPTION: користувач має від 0 до N підписок, підписка належить рівно 1 користувачу
- DATA_SOURCE - AIR_TARGET: ціль може мати від 1 до N джерел, з яких повідомили про неї. Джерела можуть мати від 0 до N відстежуваних цілей.
- CITY - AIR_TARGET: місто має від 0 до N цілей
- AIR_TARGET - THREAT_CALC: ціль має 1 актуальний розрахунок, розрахунок проводится для 0 або N цілей.
- THREAT_CALC - NOTIFICATION: оцінка створює від 0 до N сповіщень, сповіщення належить рівно 1 оцінці
- USER - NOTIFICATION: користувач отримує від 0 до N сповіщень, сповіщення адресоване рівно 1 користувачу
